# OppoF7-GSI
Guide to install a gsi on oppo f7 cph 1819(This case android 12 ponces pixel experience)

⚠️!!Important Disclaimer!!⚠️
1. I am not responsible for damage of any of your devices.
2. Follow at your own risk!
3. Note unlocking the bootloader erased your data so make sure you back up.
ℹ️Important requirements:
1. The oppo F7 (cph 1819 the 1821 could work but not sure).
2. An unlocked bootloader.
3. A linux computer (Even windows works not sure about mac) with MTK client installed with python.In windows you will need mediatek VCOM drivers with USBDK or lib32 device filter.
4. Some patience.
(Read each step carefully and don't miss a single step as it could result in a brick soft or hard!
